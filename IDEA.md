# My app

**Domain**: Student spending tracker

**User story:** As a college student on a tight budget, I need to log
what I spend each day by category, so that I can see how much I
have left this month and where my money is going.

**What the user types or picks:**
- Amount (type a number, like 12.50)
- Category (pick from a list: Food, Rent, Transportation, Books, Fun, Other)
- Date (pick from a calendar, defaults to today)
- Note (optional, type a short description, like "boba with friends")
